# Batch-Effects R Environment

## Overview

This directory contains the rix-generated R environment for batch effect correction analysis. It uses the two-phase rix workflow to provide a reproducible R environment with all required packages.

## Files

- **`generate_env.R`**: Phase 1 script that generates `default.nix` and `.Rprofile`
- **`default.nix`**: Nix expression defining the R environment (generated by rix)
- **`.Rprofile`**: R profile for library path isolation (generated by rix)
- **`run_generator.sh`**: Helper script to run Phase 1 (regenerate environment)
- **`nix_activate.sh`**: Helper script to run Phase 2 (activate environment)
- **`build_environment.sh`**: Script to build the environment for the first time
- **`test_environment.sh`**: Comprehensive test suite for the environment
- **`quick_test.sh`**: Quick validation tests (no build required)

## Environment Specifications

- **R Version**: 4.4.2 (pinned to 2024-12-14 snapshot)
- **Bioconductor**: 3.21
- **Package Count**: ~70+ packages
- **Categories**:
  - Core infrastructure (Rcpp, data.table, Matrix)
  - Tidyverse ecosystem
  - Statistical packages (glmnet, caret, ranger)
  - Bioconductor packages (limma, sva, batchelor)
  - Machine learning (xgboost, lightgbm, tidymodels)
  - Visualization (ggplot2, ComplexHeatmap, plotly)
  - Utilities (argparse, languageserver)

## Two-Phase Workflow

### Phase 1: Authoring (Generate Environment)
Run this when you want to add/remove packages or update the environment:

```bash
./run_generator.sh
```

This creates/updates:
- `default.nix` - Nix expression with pinned packages
- `.Rprofile` - Library path isolation configuration

### Phase 2: Activation (Use Environment)
Run this every time you want to use the environment:

```bash
# Interactive shell
./nix_activate.sh

# Run a specific R script
/grphome/grp_batch_effects/nix/nix-user-chroot /grphome/grp_batch_effects/nix bash -c "
  source ~/.nix-profile/etc/profile.d/nix.sh && \
  cd $(pwd) && \
  nix-shell --run 'Rscript /path/to/script.R'
"
```

## First-Time Setup

### 1. Quick Validation (No Build)
```bash
./quick_test.sh
```

This verifies:
- nix-user-chroot is available
- default.nix and .Rprofile exist
- Nix syntax is valid
- Environment can be instantiated

### 2. Build Environment (20-40 minutes)
```bash
./build_environment.sh
```

This will:
- Download pre-built binaries from rstats-on-nix cache
- Build any packages not in cache
- Create the Nix store entries
- Log progress to `build.log`

### 3. Test Environment
```bash
./test_environment.sh
```

This runs comprehensive tests:
- R version check
- Package loading (tidyverse, Bioconductor, ML packages)
- Library path isolation verification
- Sample R script execution (ComBat batch correction)
- Nix store size measurement

## Performance

- **First Build**: 20-40 minutes (downloads pre-built binaries)
- **Subsequent Activations**: ~500ms (packages cached in Nix store)
- **Storage**: ~50-100 GB in shared Nix store (shared across all group members)

## Library Path Isolation

The `.Rprofile` file ensures:
- Only packages from Nix store are used
- System R libraries are excluded
- User-installed packages (~/R/library) are excluded
- True reproducibility across all users

## Troubleshooting

### Build Fails
```bash
# Check build log
cat build.log

# Try garbage collection and rebuild
/grphome/grp_batch_effects/nix/nix-user-chroot /grphome/grp_batch_effects/nix bash -c "
  source ~/.nix-profile/etc/profile.d/nix.sh && \
  nix-collect-garbage
"
./build_environment.sh
```

### Package Not Found
If a package is missing, add it to `generate_env.R` and regenerate:
```bash
# Edit generate_env.R to add package
# Then regenerate
./run_generator.sh
# Then rebuild
./build_environment.sh
```

### Environment Activation Slow
First activation after build is slow (~500ms). Subsequent activations should be fast.

## Integration with Execution Wrapper

This environment is designed to work with `run_with_env.sh`:

```bash
# From project root
./environments/run_with_env.sh scripts/analysis.R
# Automatically detects .R extension and uses this environment
```

## Notes

- This environment uses the rstats-on-nix fork of nixpkgs
- Packages are pinned to 2024-12-14 snapshot for reproducibility
- The `parallel` package is not included (it's a base R package)
- BatchQC is excluded due to NCmisc dependency issues
- All packages are pre-built binaries from cachix (fast downloads)
